# v5 — 智慧定位與子元件拆分

面板貼底自動翻面;單檔 Select 拆成「大腦 + 臉」

---
layout: two-cols-header
---

# v5 · 兩條主線

<div class="text-sm opacity-70 -mt-2">對外 API、鍵盤、a11y 與 v4 完全相同</div>

::left::

**① 子元件拆分**

- v4 的 `Select.vue` 把六件事綁在單檔(約 500 行):
  狀態機、定位、清單導覽、typeahead、選取、渲染
- 沿「**大腦 / 臉**」與「**不變邏輯 / 會變內容**」拆開
- 邏輯進 composables、呈現進子元件、`Select.vue` 只當協調者

::right::

**② 智慧定位(flip)**

- v3/v4 面板固定向下展開,貼近視窗底部會溢出
- v5 量測下方可用空間,不足且上方較寬 → **向上翻**
- 依可用空間**夾住 max-height**,面板永不溢出視窗
- flip 就住在拆出來的 `useFloatingPosition` 裡

---

# v5 · 拆分後的結構

```text {all|2-6|8-13}{lines:true}
components/Select/
├─ composables/            # 大腦(無 template)
│  ├─ useFloatingPosition  #   定位:fixed 座標 + flip + 夾高
│  ├─ useListNavigation    #   activeIndex、略過 disabled
│  ├─ useTypeahead         #   打字比對 label
│  └─ useSelect            #   總機:組合三者 + 開合/提交/鍵盤/aria
├─ SelectTrigger.vue       # 臉:combobox 殼(aria/鍵盤/focus)
├─ SelectValue.vue         #     值顯示(會變內容,獨立成一塊)
├─ SelectDropdown.vue      #     Portal + 定位
├─ SelectOption.vue        #     <li role=option>
└─ Select.vue              # 協調者(約 100 行)
```

<div class="pt-2 text-sm opacity-60">
拆分原則:各自獨立變化 / 可重用 / 自帶非平凡狀態,三選一才拆;純呈現葉節點(箭頭)不拆
</div>

---

# v5 · 相對 v4 的差異

| 面向 | v4 | v5 |
| --- | --- | --- |
| 檔案結構 | 單檔 `Select.vue`(約 500 行) | 4 composables + 5 元件,協調者約 100 行 |
| 邏輯重用 | 綁死在元件內 | `useFloatingPosition` 等可被其他浮層重用 |
| 面板展開方向 | 固定向下 | **依空間翻面(flip),不足向上開** |
| 面板高度 | 固定 `max-height: 240` | **依可用空間動態夾住**,不溢出視窗 |
| 對外 API | — | **與 v4 相同(可直接替換)** |

<div class="pt-3 text-sm opacity-60">
完整差異記錄於 <code>src/packages/v5/CHANGELOG.md</code>
</div>
