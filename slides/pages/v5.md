# v5 — 面板會翻面，元件也拆開了

空間不夠就往上開；單檔 Select 拆成「大腦 + 臉」

---
layout: two-cols-header
---

# v5 · 這版做了兩件事

<div class="text-sm opacity-70 -mt-2">對外 API、鍵盤、a11y 跟 v4 完全一樣</div>

::left::

**① 把元件拆開**

- v4 的 `Select.vue` 把六件事塞在同一個檔（大概 500 行）：
  狀態機、定位、清單導覽、typeahead、選取、渲染
- 照「**大腦 / 臉**」跟「**不會變的邏輯 / 會變的內容**」下刀
- 邏輯搬進 composables、呈現搬進子元件，`Select.vue` 只當協調的那個

::right::

**② 面板會自己翻面（flip）**

- v3/v4 的面板一律往下開，貼到視窗底部就溢出去了
- v5 會量下面還剩多少，不夠而且上面比較寬 → **往上翻**
- 再照剩下的空間**把 max-height 夾住**，面板不會再溢出視窗
- flip 就住在剛拆出來的 `useFloatingPosition` 裡面

---

# v5 · 拆完長這樣

```text {all|2-6|8-13}{lines:true}
components/Select/
├─ composables/            # 大腦（沒有 template）
│  ├─ useFloatingPosition  #   定位：fixed 座標 + flip + 夾高
│  ├─ useListNavigation    #   activeIndex、自動跳過 disabled
│  ├─ useTypeahead         #   打字比對 label
│  └─ useSelect            #   總機：把三個組起來 + 開合/提交/鍵盤/aria
├─ SelectTrigger.vue       # 臉：combobox 的殼（aria/鍵盤/focus）
├─ SelectValue.vue         #     顯示值（會變的內容，獨立一塊）
├─ SelectDropdown.vue      #     Portal + 定位
├─ SelectOption.vue        #     <li role=option>
└─ Select.vue              # 協調者（大概 100 行）
```

<div class="pt-2 text-sm opacity-60">
拆的標準：會各自變、能重用、自己帶著不簡單的狀態——中一個才拆；純呈現的葉節點（像箭頭）就別拆了
</div>

# v5 · 跟 v4 差在哪

| 面向 | v4 | v5 |
| --- | --- | --- |
| 檔案結構 | 一個 `Select.vue` 扛完（約 500 行） | 4 個 composables + 5 個元件，協調者剩約 100 行 |
| 邏輯能不能重用 | 綁死在元件裡 | `useFloatingPosition` 這些，其他浮層也拿得走 |
| 面板往哪開 | 一律往下 | **看空間翻面（flip），不夠就往上開** |
| 面板高度 | 寫死 `max-height: 240` | **照剩下的空間動態夾住**，不溢出視窗 |
| 對外 API | — | **跟 v4 相同（可以直接換掉）** |

<div class="pt-3 text-sm opacity-60">
完整差異都寫在 <code>src/packages/v5/CHANGELOG.md</code>
</div>
