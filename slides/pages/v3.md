# v3 — 把面板 Portal 出去

解掉 v2 的天生缺陷：讓面板不再被父層的 `overflow` 綁著

---
layout: two-cols-header
---

# v3 · 這版想幹嘛

<div class="text-sm opacity-70 -mt-2">多做一個 Portal 元件，Select 的 API 一個字都不用改</div>

::left::

**踩到的坑**

- v2 的面板是 `position: absolute`，貼著父層定位
- 只要祖先有人掛了 `overflow: hidden / auto / scroll`
  （卡片、對話框、表格、側邊欄，到處都是）
- 超出容器的面板就被**切掉**，選項點不到

::right::

**怎麼爬出來**

- ✅ 生一個 **`Portal` 元件**（`<Teleport>` 薄薄包一層，預設送 `body`）
- ✅ Select 的面板改由 Portal 送去 `<body>`
- ✅ 改用 `position: fixed` + trigger 的 viewport 座標來定位
- ✅ 對外 API 跟 v2 **一模一樣**（import `@v2` → `@v3`）

<div class="pt-2 text-sm opacity-60">
→ 面板脫離了父層的 stacking context 跟 overflow，誰都切不到它
</div>

---

# v3 · 跟 v2 差在哪

| 面向 | v2 | v3 |
| --- | --- | --- |
| 面板掛在哪 | 元件父層裡（`<ul>` 是 root 的子節點） | 用 `Portal` 送去 `<body>` |
| 怎麼定位 | `position: absolute` 貼父層 | `position: fixed` + trigger 的 viewport 座標 |
| 會不會被 `overflow` 切 | ⚠️ 會，切得很乾脆 | ✅ 切不到 |
| 捲動 / resize | 面板跟著父層跑 | 監聽 `scroll`(capture) / `resize` 即時校正 |
| 對外 API | — | **跟 v2 相同（可以直接換掉）** |

<div class="pt-3 text-sm opacity-60">
完整差異都寫在 <code>src/packages/v3/CHANGELOG.md</code>
</div>
