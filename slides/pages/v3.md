# v3 — Portal 傳送下拉面板

解掉 v2 的先天限制：讓面板脫離父層 `overflow` 的束縛

---
layout: two-cols-header
---

# v3 · 設計目標

<div class="text-sm opacity-70 -mt-2">追加一個 Portal 元件，Select API 一個字都不用改</div>

::left::

**要解的題**

- v2 面板用 `position: absolute` 相對父層定位
- 只要祖先層有 `overflow: hidden / auto / scroll`
  （卡片、對話框、表格、側邊欄）
- 超出容器的面板就被**裁切**，選項點不到

::right::

**怎麼解**

- ✅ 新增 **`Portal` 元件**（`<Teleport>` 薄封裝，預設送 `body`）
- ✅ Select 面板改由 Portal 傳送到 `<body>`
- ✅ 改用 `position: fixed` + trigger 的 viewport 座標定位
- ✅ 對外 API 與 v2 **完全相同**（import `@v2` → `@v3`）

<div class="pt-2 text-sm opacity-60">
→ 面板脫離父層 stacking context 與 overflow，任何祖先都裁不到它
</div>

---

# v3 · 相對 v2 的差異

| 面向 | v2 | v3 |
| --- | --- | --- |
| 面板掛載位置 | 元件父層內（`<ul>` 是 root 子節點） | 透過 `Portal` 傳送到 `<body>` |
| 定位方式 | `position: absolute` 相對父層 | `position: fixed` + trigger viewport 座標 |
| 受父層 `overflow` 影響 | ⚠️ 會被裁切 | ✅ 不受影響 |
| 捲動 / resize | 面板隨父層 | 監聽 `scroll`(capture) / `resize` 即時校正 |
| 對外 API | — | **與 v2 相同（可直接替換）** |

<div class="pt-3 text-sm opacity-60">
完整差異記錄於 <code>src/packages/v3/CHANGELOG.md</code>
</div>

# v3 · 核心實作

```vue {all|2|8-15|18-22}{lines:true,maxHeight:'320px'}
<template>
  <Portal>
    <!-- 面板被傳送到 body，用行內 fixed 座標定位 -->
    <ul v-show="isOpen" ref="dropdownRef"
        class="bs-select__dropdown" :style="dropdownStyle">
      <li v-for="opt in options" ...>{{ opt.label }}</li>
    </ul>
  </Portal>
</template>

<script setup lang="ts">
function updatePosition() {
  const rect = rootRef.value.getBoundingClientRect();
  dropdownStyle.value = {
    position: "fixed",
    top: `${rect.bottom + 4}px`,
    left: `${rect.left}px`,
    minWidth: `${rect.width}px`,
  };
}
// 開啟時 addEventListener('scroll', updatePosition, true) + 'resize'
// 外部點擊關閉：需同時排除 trigger 與「已傳送的」面板
</script>
```

# v3 · Portal 元件

<div class="text-sm opacity-70 -mt-2">對 Vue 內建 <code>&lt;Teleport&gt;</code> 的薄封裝，成為浮層元件的共用基礎</div>

```vue {all|3-4|9}{lines:true}
<script setup lang="ts">
withDefaults(defineProps<{
  to?: string | HTMLElement;   // 傳送目標，預設 <body>
  disabled?: boolean;          // 停用傳送，內容留在原地
}>(), { to: "body", disabled: false });
</script>

<template>
  <Teleport :to="to" :disabled="disabled"><slot /></Teleport>
</template>
```

<div class="pt-2 text-sm opacity-60">
下拉、Modal、Tooltip 之後都能共用這一個 Portal —— 統一「浮出父層」的做法
</div>
