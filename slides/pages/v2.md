# v2 · 這版想幹嘛

<div class="text-sm opacity-70 -mt-2">API 一個字不動，底層整個換掉 —— 用的人無痛升級</div>

**做了什麼**

- 改成 `<div>` 當 trigger、`<ul>`/`<li>` 當面板，原生 `<select>` 退場
- 下拉長相**完全自己說了算**，跨平台終於一致
- option 的 hover / selected / disabled 樣式（純 CSS 就搞定）
- 點 trigger 開合、點選項選取、點外面自動收起來
- 對外 API 跟 v1 **一模一樣**（`modelValue` / `options` / `size` / `disabled` / Emits / 型別，全都沒動）

<div class="pt-2 text-sm opacity-60">
→ import 從 <code>@v1</code> 改成 <code>@v2</code>，就這樣
</div>

# v2 · 跟 v1 差在哪

| 面向 | v1 | v2 |
| --- | --- | --- |
| 底層結構 | 原生 `<select>` / `<option>` | `<div>` trigger + `<ul>`/`<li>` 面板 |
| 下拉長相 | 瀏覽器原生（各 OS 各長各的） | 自己畫，跨平台一致 |
| option 樣式 | 動不了 | hover / selected / disabled / 箭頭動畫 |
| 對外 API | — | **跟 v1 相同（可以直接換掉）** |

<div class="pt-3 text-sm opacity-60">
完整差異都寫在 <code>src/packages/v2/CHANGELOG.md</code>
</div>
