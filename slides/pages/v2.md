# v2 — 自訂 `<div>` 下拉選單

拿回主導權：把原生 `<select>` 重構成完全可控的下拉面板

---

# v2 · 設計目標

<div class="text-sm opacity-70 -mt-2">API 不動，換掉整個底層 —— 使用端可無痛升級</div>

**做了什麼**

- 以 `<div>` trigger + `<ul>`/`<li>` 面板取代原生 `<select>`
- 下拉外觀**完全自訂**、跨平台一致
- option 的 hover / selected / disabled 樣式（純 CSS）
- 點擊 trigger 開合、點選選項、點外部自動收合
- 對外 API 與 v1 **完全相同**（`modelValue` / `options` / `size` / `disabled` / Emits / 型別皆不變）

<div class="pt-2 text-sm opacity-60">
→ import 從 <code>@v1</code> 換成 <code>@v2</code> 即可
</div>

---

# v2 · 相對 v1 的差異

| 面向 | v1 | v2 |
| --- | --- | --- |
| 底層結構 | 原生 `<select>` / `<option>` | `<div>` trigger + `<ul>`/`<li>` 面板 |
| 下拉外觀 | 瀏覽器原生（各 OS 不一致） | 完全自訂、跨平台一致 |
| option 樣式 | 無法自訂 | hover / selected / disabled / 箭頭動畫 |
| 對外 API | — | **與 v1 相同（可直接替換）** |

<div class="pt-3 text-sm opacity-60">
完整差異記錄於 <code>src/packages/v2/CHANGELOG.md</code>
</div>
