# v2 — 自訂 `<div>` 下拉選單

拿回主導權：把原生 `<select>` 重構成完全可控的下拉面板

---
layout: two-cols-header

# v2 · 設計目標

<div class="text-sm opacity-70 -mt-2">API 不動，換掉整個底層 —— 使用端可無痛升級</div>

::left::

**做了什麼**

- 以 `<div>` trigger + `<ul>`/`<li>` 面板取代原生 `<select>`
- 下拉外觀**完全自訂**、跨平台一致
- option 的 hover / selected / disabled 樣式（純 CSS）
- 點擊 trigger 開合、點選選項、點外部自動收合

::right::

**刻意維持陽春 / 不做**

- ✅ 對外 API 與 v1 **完全相同**（`modelValue` / `options` / `size` / `disabled` / Emits / 型別皆不變）
- ❌ 鍵盤操作（↑↓ / Enter / Esc …）
- ❌ 無障礙（ARIA combobox / listbox）

<div class="pt-2 text-sm opacity-60">
→ import 從 <code>@v1</code> 換成 <code>@v2</code> 即可｜鍵盤與無障礙留待後續版本
</div>

# v2 · 相對 v1 的差異

| 面向 | v1 | v2 |
| --- | --- | --- |
| 底層結構 | 原生 `<select>` / `<option>` | `<div>` trigger + `<ul>`/`<li>` 面板 |
| 下拉外觀 | 瀏覽器原生（各 OS 不一致） | 完全自訂、跨平台一致 |
| option 樣式 | 無法自訂 | hover / selected / disabled / 箭頭動畫 |
| 鍵盤操作 | 瀏覽器內建 | ❌ 尚未處理（後續版本） |
| 無障礙 | 免費繼承原生 | ❌ 尚未處理（後續版本） |
| 對外 API | — | **與 v1 相同（可直接替換）** |

<div class="pt-3 text-sm opacity-60">
完整差異記錄於 <code>src/packages/v2/CHANGELOG.md</code>
</div>

# v2 · 核心實作

```vue {all|2-4|6-9|11-14}{lines:true,maxHeight:'320px'}
<template>
  <div ref="rootRef" :class="rootClasses">
    <!-- trigger：可自訂外觀、旋轉箭頭 -->
    <div class="bs-select__trigger" @click="toggle">
      <span class="bs-select__value">{{ selectedOption?.label ?? placeholder }}</span>
      <span class="bs-select__arrow" />
    </div>

    <!-- 自訂面板：ul/li，樣式完全可控 -->
    <ul v-show="isOpen" class="bs-select__dropdown">
      <li v-for="opt in options" :key="opt.value"
          class="bs-select__option"
          @click="selectOption(opt)">{{ opt.label }}</li>
    </ul>
  </div>
</template>
```

<div class="pt-2 text-sm opacity-60">
陽春版：只在 <code>&lt;script setup&gt;</code> 內處理開合狀態與點擊外部收合，hover 交給純 CSS
</div>
