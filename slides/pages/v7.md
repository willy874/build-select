# v7 · 這版想幹嘛

<div class="text-sm opacity-70 -mt-2">用 multiple 這個 prop 自己開，不加就跟 v6 一模一樣</div>

::left::

**要解的事**

- 就是要一次選好幾個（標籤、分類、收件人）
- 原生 `<select multiple>` 那個體驗⋯⋯算了吧
- 已經選了什麼要看得到，也要好拔掉
- 最好還能**邊搜尋邊多選**

::right::

**怎麼做**

- ✅ 加一個 `multiple` prop（預設 `false`）
- ✅ `modelValue` 變成**陣列**；選取改成 toggle，面板**不關**
- ✅ 已選的變成**可以拔掉的 chips**，選項上打 `✓`
- ✅ 可以跟 `filterable` 併用：chips + 搜尋框
- ✅ 對外相容 v6（不加 `multiple` 行為完全不變）

<div class="pt-2 text-sm opacity-60">
拆分的紅利又來了：多選的差異幾乎只落在 useSelect 的選取邏輯
</div>

---

# v7 · 三種 trigger（排列組合）

<div class="text-sm opacity-70 -mt-2">filterable × multiple 兩個互不干涉的 prop，四種組合，三個 trigger 元件</div>

| filterable | multiple | trigger 元件 |
| --- | --- | --- |
| false | false | `SelectTrigger`（div，v5/v6） |
| true | false | `SelectSearchInput`（input，v6） |
| false | true | `SelectMultiTrigger`（chips + div） |
| true | true | `SelectSearchInput` + chips |

<div class="pt-3 text-sm leading-relaxed">

- 多做一個 `SelectChips`（可以拔掉的標籤），給多選的兩種 trigger 共用
- `SelectOption` 加勾選、`SelectDropdown` 加 `aria-multiselectable`
- `Select.vue` 照 `(filterable, multiple)` 挑一個 trigger 渲染

</div>

# v7 · 跟 v6 差在哪

| 面向 | v6 | v7 |
| --- | --- | --- |
| `modelValue` | 單一個值 | multiple 時變**陣列** |
| 選了會怎樣 | 蓋掉舊的然後關起來 | multiple：toggle，而且**面板不關** |
| 已選怎麼呈現 | 就一個值 | **可以拔掉的 chips** + 選項打 `✓` |
| 搜尋多選 | — | multiple + filterable：chips + 搜尋框，`Backspace` 直接拔 |
| 對外 API | — | 多一個 `multiple`（預設 false），其他都沒動 |

<div class="pt-3 text-sm opacity-60">
完整差異都寫在 <code>src/packages/v7/CHANGELOG.md</code>
</div>
