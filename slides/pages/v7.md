# v7 · 設計目標

<div class="text-sm opacity-70 -mt-2">以 multiple prop 選擇性開啟,不加就與 v6 完全一樣</div>

::left::

**要做的事**

- 一次選多個(標籤、分類、收件人)
- 原生 `<select multiple>` 體驗差
- 已選要看得到、好移除
- 最好還能**邊搜尋邊多選**

::right::

**怎麼做**

- ✅ 新增 `multiple` prop(預設 `false`)
- ✅ `modelValue` 變**陣列**;選取為 toggle、面板**不關**
- ✅ 已選以**可移除 chips**、選項顯示 `✓`
- ✅ 可與 `filterable` 併用:chips + 搜尋框
- ✅ 對外 API 相容 v6(不加 `multiple` 行為不變)

<div class="pt-2 text-sm opacity-60">
拆分紅利:多選差異幾乎只落在 useSelect 的選取邏輯
</div>

---

# v7 · 三種 trigger(組合矩陣)

<div class="text-sm opacity-70 -mt-2">filterable × multiple 兩個正交 prop,對應四種組合、三個 trigger 元件</div>

| filterable | multiple | trigger 元件 |
| --- | --- | --- |
| false | false | `SelectTrigger`(div,v5/v6) |
| true | false | `SelectSearchInput`(input,v6) |
| false | true | `SelectMultiTrigger`(chips + div) |
| true | true | `SelectSearchInput` + chips |

<div class="pt-3 text-sm leading-relaxed">

- 新增 `SelectChips`(可移除標籤),供多選的兩種 trigger 共用
- `SelectOption` 加勾選、`SelectDropdown` 加 `aria-multiselectable`
- `Select.vue` 依 `(filterable, multiple)` 擇一渲染 trigger

</div>

---

# v7 · 相對 v6 的差異

| 面向 | v6 | v7 |
| --- | --- | --- |
| `modelValue` | 純量 | multiple 時為**陣列** |
| 選取行為 | 取代並關閉 | multiple:toggle、**面板不關** |
| 已選呈現 | 單一值 | **可移除 chips** + 選項 `✓` |
| 搜尋多選 | — | multiple + filterable:chips + 搜尋框、`Backspace` 移除 |
| 對外 API | — | 新增 `multiple`(預設 false),其餘不變 |

<div class="pt-3 text-sm opacity-60">
完整差異記錄於 <code>src/packages/v7/CHANGELOG.md</code>
</div>
