# v6 · 設計目標

<div class="text-sm opacity-70 -mt-2">以 filterable prop 選擇性開啟,不加就與 v5 完全一樣</div>

::left::

**要做的事**

- 長清單(縣市、使用者、商品)需要**打字過濾**
- 原生 `<select>` 與 v1~v5 都給不了
- 中文情境還要能打**拼音**快速找

::right::

**怎麼做**

- ✅ 新增 `filterable` prop(預設 `false`)
- ✅ 開啟時 trigger 變**可輸入 combobox**,打字即過濾
- ✅ 拼音模糊比對(`pinyin-pro`)+ 一般子字串
- ✅ 命中片段**高亮**、無命中顯示「無結果」
- ✅ 對外 API 相容 v5(不加 `filterable` 行為不變)

<div class="pt-2 text-sm opacity-60">
拆分紅利:v5 保留的「值顯示區」縫隙,這一版直接換成搜尋 input
</div>

---

# v6 · 相對 v5 的差異

| 面向 | v5 | v6 |
| --- | --- | --- |
| trigger | 靜態 `<div role=combobox>` | filterable 時換 `<input role=combobox>` |
| 打字行為 | typeahead 跳項 | filterable 時**過濾**清單 |
| 中文搜尋 | ❌ | ✅ 拼音(首字母 / 全拼)+ 子字串 |
| 命中呈現 | — | **高亮命中片段**、無命中「無結果」 |
| 對外 API | — | 新增 `filterable`(預設 false),其餘不變 |

<div class="pt-3 text-sm opacity-60">
新增相依 <code>pinyin-pro</code>;完整差異記錄於 <code>src/packages/v6/CHANGELOG.md</code>
</div>
