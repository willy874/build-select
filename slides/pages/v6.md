# v6 · 設計目標

<div class="text-sm opacity-70 -mt-2">以 filterable prop 選擇性開啟,不加就與 v5 完全一樣</div>

::left::

**要做的事**

- 長清單(縣市、使用者、商品)需要**打字過濾**
- 原生 `<select>` 與 v1~v5 都給不了
- 中文情境還要能打**拼音**快速找

::right::

**怎麼做**

- ✅ 新增 `filterable` prop(預設 `false`)
- ✅ 開啟時 trigger 變**可輸入 combobox**,打字即過濾
- ✅ 拼音模糊比對(`pinyin-pro`)+ 一般子字串
- ✅ 命中片段**高亮**、無命中顯示「無結果」
- ✅ 對外 API 相容 v5(不加 `filterable` 行為不變)

<div class="pt-2 text-sm opacity-60">
拆分紅利:v5 保留的「值顯示區」縫隙,這一版直接換成搜尋 input
</div>

# v6 · 搜尋比對(拼音 + 子字串)

<div class="text-sm opacity-70 -mt-2">新增純函式 <code>filterOptions</code>,回傳命中字元索引供高亮</div>

```ts {all|4-7|9-14}{lines:true,maxHeight:'320px'}
import { match } from "pinyin-pro";

function matchLabel(label: string, query: string): number[] | null {
  // 1) 一般子字串(可打中文字 / 拉丁 label)
  const at = label.toLowerCase().indexOf(query.toLowerCase());
  if (at >= 0)
    return Array.from({ length: query.length }, (_, i) => at + i);

  // 2) 拼音比對:首字母 / 全拼 / 混合,回傳命中的字元索引
  if (isAscii(query)) {
    const py = match(label, query); // 'pg' → 蘋果 → [0,1]
    if (py && py.length) return py;
  }
  return null; // 皆未命中
}
```

<div class="pt-1 text-sm opacity-60">
<code>pg</code>→蘋果、<code>xj</code>→香蕉、<code>qyg</code>→奇異果、<code>xiangjiao</code>→香蕉;命中索引直接餵給 <code>&lt;mark&gt;</code> 高亮
</div>

# v6 · 可輸入的 combobox

<div class="text-sm opacity-70 -mt-2">SelectSearchInput:input 值永遠 = query,已選值用 overlay 顯示</div>

```vue {all|4-8|10-13}{lines:true,maxHeight:'320px'}
<div class="bs-select__trigger">
  <span class="bs-select__field">
    <!-- role/aria-autocomplete 落在 input;value 永遠是 query -->
    <input role="combobox" aria-autocomplete="list"
           :value="query" :aria-controls="listboxId"
           :aria-activedescendant="activeDescendant"
           @input="emit('input', $event.target.value)"
           @keydown="emit('keydown', $event)" />
    <!-- query 為空時,用非互動 overlay 顯示已選值 / placeholder -->
    <span v-if="query === ''" class="bs-select__overlay">
      {{ selectedLabel ?? placeholder }}
    </span>
  </span>
</div>
```

<div class="pt-1 text-sm opacity-60">
input 值不放已選 label,避免「已選值混進搜尋字串」;非 filterable 時仍用 v5 的 <code>SelectTrigger</code>(div)
</div>

# v6 · 相對 v5 的差異

| 面向 | v5 | v6 |
| --- | --- | --- |
| trigger | 靜態 `<div role=combobox>` | filterable 時換 `<input role=combobox>` |
| 打字行為 | typeahead 跳項 | filterable 時**過濾**清單 |
| 中文搜尋 | ❌ | ✅ 拼音(首字母 / 全拼)+ 子字串 |
| 命中呈現 | — | **高亮命中片段**、無命中「無結果」 |
| 對外 API | — | 新增 `filterable`(預設 false),其餘不變 |

新增相依 <code>pinyin-pro</code>;完整差異記錄於 <code>src/packages/v6/CHANGELOG.md</code>
</div>
