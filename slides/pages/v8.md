# v8 · 這版想幹嘛

<div class="text-sm opacity-70 -mt-2">三塊能力都是選配的 prop，不加就跟 v7 一樣</div>

::left::

**要解的事**

- v6 的搜尋只能過濾「已經在前端」的那些
- 真實資料動不動就上千上萬筆：
  - 一次全塞前端 → **渲染直接爆掉**
  - 全部載下來 → 想也知道不可能
- 所以要：只渲染看得到的 + 邊捲邊載 + 直接打後端

::right::

**怎麼做**

- ✅ **虛擬列表**（`virtual`）：只渲染看得到的那幾列
- ✅ **無限滾動**：捲到底就送 `load-more`，外面載下一頁 append 進來
- ✅ **遠端**（`remote`）：不在本地過濾，`query` 直接送 `search`
- ✅ 全部走事件、由外部控；跟 `filterable` / `multiple` 併用也沒問題
- ✅ 對外相容 v7

---

# v8 · 跟 v7 差在哪

| 面向 | v7 | v8 |
| --- | --- | --- |
| 長清單怎麼渲染 | 全部塞進 DOM | `virtual`：只渲染看得到的（5000 筆 → 約 15 列） |
| 資料從哪來 | 全在前端 | `remote`：query 送 `search`，交給外面去查 |
| 分頁 | — | 無限滾動：捲到底送 `load-more` 再 append |
| 狀態 | 沒選項 / 沒結果 | 再加：載入中 / 請先輸入 / 底部載入中 |
| 對外 API | — | 多了 `virtual`/`itemHeight`/`remote`/`loading`/`finished` + `search`/`load-more` |
