# v8 · 設計目標

<div class="text-sm opacity-70 -mt-2">三塊能力皆選擇性 prop,不加就與 v7 一樣</div>

::left::

**要解的題**

- v6 搜尋只能過濾「已在前端」的清單
- 真實資料動輒上千上萬筆:
  - 一次塞前端 → **渲染超載**
  - 全下載 → 不切實際
- 需要:只渲染看得到的 + 邊捲邊載 + 打到伺服器

::right::

**怎麼解**

- ✅ **虛擬列表**(`virtual`):只渲染可視範圍
- ✅ **無限滾動**:捲到底送 `load-more`,外部載下一頁 append
- ✅ **遠端**(`remote`):不本地過濾,`query` 送 `search`
- ✅ 事件式受控;與 `filterable` / `multiple` 併用
- ✅ 對外 API 相容 v7

# v8 · 虛擬列表(useVirtualList)

<div class="text-sm opacity-70 -mt-2">phantom 撐出總高 + translateY 偏移,只渲染窗內十幾列</div>

```ts {all|4-10|13-14}{lines:true,maxHeight:'320px'}
export function useVirtualList(itemCount, itemHeight, overscan = 4) {
  const scrollTop = ref(0), viewportHeight = ref(0);

  const range = computed(() => {                 // 依 scrollTop 算渲染窗
    const start = Math.max(0,
      Math.floor(scrollTop.value / itemHeight.value) - overscan);
    const visible = Math.ceil(viewportHeight.value / itemHeight.value);
    const end = Math.min(itemCount.value, start + visible + overscan * 2);
    return { start, end };
  });
  const totalHeight = computed(() => itemCount.value * itemHeight.value);
  const offsetY = computed(() => range.value.start * itemHeight.value);
  function setViewport(top, h) { scrollTop.value = top; viewportHeight.value = h; }
  function scrollOffsetFor(i) { /* 讓 i 進入可視範圍的 scrollTop */ }
  return { range, totalHeight, offsetY, setViewport, scrollOffsetFor };
}
```

<div class="pt-1 text-sm opacity-60">
a11y:渲染的選項帶 <code>aria-setsize</code>/<code>aria-posinset</code>;鍵盤高亮用 <code>scrollOffsetFor</code> 確保 active 項有被渲染
</div>

# v8 · 無限滾動 + 遠端(事件式受控)

<div class="text-sm opacity-70 -mt-2">元件只送事件,fetch / 分頁 / loading 由呼叫端掌控</div>

```ts {all|2-3|6-9}{lines:true,maxHeight:'320px'}
// 元件端(useSelect / Select.vue)
open()        → remote && emit('search', query)     // 開啟載入第一頁
onQueryInput  → remote && debounce(emit('search', q)) // 打字重新查詢
onPanelScroll → 近底部 && !loading && !finished
                && emit('loadMore')                  // 捲到底載下一頁

// 呼叫端
@search="q => { page=0; options = await fetch(q, 0) }"
@load-more="() => { options.push(...await fetch(q, ++page)) }"
:loading :finished    // 控制載入列與是否停止
```

<div class="pt-1 text-sm opacity-60">
狀態列:輸入以搜尋 / 載入中… / 無結果 / 底部載入中…;符合現有 v-model + options 受控風格
</div>

# v8 · 相對 v7 的差異

| 面向 | v7 | v8 |
| --- | --- | --- |
| 長清單渲染 | 全部進 DOM | `virtual`:只渲染可視窗(5000 筆→約 15 列) |
| 資料來源 | 全在前端 | `remote`:query 送 `search`,外部查詢 |
| 分頁 | — | 無限滾動:捲到底送 `load-more` append |
| 狀態 | 無選項 / 無結果 | + 載入中 / 輸入以搜尋 / 底部載入中 |
| 對外 API | — | 新增 `virtual`/`itemHeight`/`remote`/`loading`/`finished` + `search`/`load-more` |
