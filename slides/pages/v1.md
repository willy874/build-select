# v1 — 原生 `<select>` 包裝

打好地基：最小可用、可上線的第一版

---

# v1 · 設計目標

<div class="text-sm opacity-70 -mt-2">用最少的程式碼，換到最穩的行為</div>

**做了什麼**

- 包裝原生 `<select>`，行為與無障礙**免費繼承**
- `v-model` 雙向綁定（`modelValue` + `update:modelValue`）
- `options` 陣列驅動，支援 `disabled` 單項停用
- `size`：`small` / `medium` / `large`
- `placeholder` 以 disabled hidden option 呈現

---

# v1 · API

| Prop | 型別 | 預設 | 說明 |
| --- | --- | --- | --- |
| `modelValue` | `string \| number \| null` | `null` | 目前選取值（v-model） |
| `options` | `SelectOption[]` | `[]` | 選項清單 |
| `placeholder` | `string` | `"請選擇"` | 未選取時提示 |
| `size` | `"small" \| "medium" \| "large"` | `"medium"` | 尺寸 |
| `disabled` | `boolean` | `false` | 是否整體停用 |

<div class="pt-3 text-sm">

**Emits**：`update:modelValue`、`change` ｜
**型別**：`SelectOption = { label; value; disabled? }`

</div>

# v1 · 核心實作

```vue {all|4-8|12-15|3-6}{lines:true}
<script setup lang="ts">
export interface SelectOption {
  label: string;
  value: string | number;
  disabled?: boolean;
}
// props: modelValue / options / placeholder / size / disabled
function onChange(event: Event) {
  const raw = (event.target as HTMLSelectElement).value;
  const matched = options.find((o) => String(o.value) === raw);
  emit("update:modelValue", matched ? matched.value : null);
}
</script>

<template>
  <select :value="modelValue === null ? '' : String(modelValue)" @change="onChange">
    <option value="" disabled hidden>{{ placeholder }}</option>
    <option v-for="o in options" :key="o.value" :value="String(o.value)" :disabled="o.disabled">
      {{ o.label }}
    </option>
  </select>
</template>
```
