# v1 · 這版想幹嘛

<div class="text-sm opacity-70 -mt-2">用最少的程式碼，換最穩的行為</div>

**做了什麼**

- 包一層原生 `<select>`，行為跟無障礙**直接白嫖**
- `v-model` 雙向綁定（`modelValue` + `update:modelValue`）
- 用 `options` 陣列餵資料，單項可以 `disabled`
- `size`：`small` / `medium` / `large`
- `placeholder` 用 disabled hidden option 撐出來
