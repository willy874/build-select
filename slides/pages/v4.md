# v4 · 這版想幹嘛

<div class="text-sm opacity-70 -mt-2">讓這顆自訂 Select 只用鍵盤、只靠螢幕閱讀器也能整套操作，API 一個字都不用改</div>

::left::

**欠了什麼債**

- v1 的原生 `<select>` 免費送我：`Tab` 聚焦、
  方向鍵移動、打字跳項、`Enter` / `Esc` 開合、
  還有螢幕閱讀器讀得懂的語意
- v2 為了搶回外觀主導權，**這些全丟了**
- v3 忙著解 overflow，根本沒空理這塊

::right::

**怎麼還**

- ✅ **鍵盤**：方向鍵 / `Home` / `End` / `Enter` / `Esc` / typeahead
- ✅ **焦點**：`Tab` 進得來、有 focus ring、關掉會把焦點收回來
- ✅ **ARIA 語意**：`combobox` + `listbox` + `option`
- ✅ 對外 API 跟 v3 **一模一樣**（import `@v3` → `@v4`）

<div class="pt-2 text-sm opacity-60">
→ 繞了一圈，才把原生本來就有的可及性（accessibility）補回來
</div>

# v4 · 鍵盤都怎麼按

<div class="text-sm opacity-70 -mt-2">先聚焦到 trigger（`disabled` 的話會被移出 tab 序）</div>

| 按鍵 | 會發生什麼 |
| --- | --- |
| `↓` / `↑` | 關著就打開；開著就上下移動高亮 |
| `Home` / `End` | 跳到第一個 / 最後一個可選的 |
| `Enter` / `Space` | 打開面板，或直接選走現在高亮那個 |
| `Esc` | 關掉面板，焦點收回 trigger |
| `Tab` | 關掉面板，然後放行（焦點自然離開） |
| 可列印字元 | **typeahead**：跳到 label 開頭對得上的那個 |

<div class="pt-2 text-sm opacity-60">
鍵盤走的時候**會自動跳過 <code>disabled</code>**；高亮跑出可視範圍就自動 <code>scrollIntoView</code>
</div>

# v4 · 跟 v3 差在哪

| 面向 | v3 | v4 |
| --- | --- | --- |
| 鍵盤 | ❌ 只能用滑鼠點 | ✅ 方向鍵 / Home / End / Enter / Esc / typeahead |
| 焦點 | ❌ `Tab` 進不來、沒有 focus ring | ✅ 聚焦得到、有 focus ring、關掉會收回來 |
| ARIA 語意 | ❌ 就是一堆 div/ul/li | ✅ `combobox` + `listbox` + `option` |
| 高亮誰在管 | CSS `:hover` | `activeIndex`（鍵盤跟滑鼠共用一套） |
| 對外 API | — | **跟 v3 相同（可以直接換掉）** |

<div class="pt-3 text-sm opacity-60">
完整差異都寫在 <code>src/packages/v4/CHANGELOG.md</code>
</div>
