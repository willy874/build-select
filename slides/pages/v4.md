# v4 · 鍵盤操作對照表

<div class="text-sm opacity-70 -mt-2">聚焦 trigger 後（disabled 時移出 tab 序）</div>

| 按鍵 | 行為 |
| --- | --- |
| `↓` / `↑` | 關閉時開啟面板；開啟時上下移動高亮 |
| `Home` / `End` | 跳到第一 / 最後一個可選項 |
| `Enter` / `Space` | 開啟面板，或選取目前高亮項 |
| `Esc` | 關閉面板，焦點收回 trigger |
| `Tab` | 關閉面板並放行預設行為（焦點自然離開） |
| 可列印字元 | **typeahead**：跳到 label 符合開頭的選項 |

<div class="pt-2 text-sm opacity-60">
鍵盤導覽**自動略過 <code>disabled</code> 選項**；高亮超出可視區時自動 <code>scrollIntoView</code>
</div>

# v4 · ARIA combobox 模式

<div class="text-sm opacity-70 -mt-2">焦點固定在 trigger，用 <code>aria-activedescendant</code> 指向高亮選項達成「虛擬焦點」</div>

```vue {all|4-8|13-16}{lines:true,maxHeight:'320px'}
<template>
  <!-- trigger 即 combobox -->
  <div class="bs-select__trigger"
       role="combobox" :tabindex="disabled ? -1 : 0"
       :aria-expanded="isOpen"
       :aria-controls="listboxId"
       aria-haspopup="listbox"
       :aria-activedescendant="activeDescendant"
       @keydown="onKeydown">…</div>

  <Portal>
    <ul :id="listboxId" role="listbox">
      <li v-for="(opt, i) in options" :id="optionId(i)"
          role="option" :aria-selected="opt.value === modelValue"
          :aria-disabled="opt.disabled || undefined"
          :class="{ 'bs-select__option--active': i === activeIndex }">…</li>
    </ul>
  </Portal>
</template>
```

<div class="pt-1 text-sm opacity-60">
面板 Portal 到 <code>body</code>、且會頻繁掛載/卸載 → 焦點移進去難管；combobox 模式讓焦點留在 trigger，螢幕閱讀器仍能播報高亮項
</div>

# v4 · 鍵盤導覽核心

<div class="text-sm opacity-70 -mt-2">高亮索引 <code>activeIndex</code> 為單一真相，鍵盤與滑鼠共用</div>

```ts {all|2-8|11-14|17-22}{lines:true,maxHeight:'320px'}
// 往 dir 方向找下一個「未停用」選項，找不到就停在原地（不環繞）
function nextEnabled(from: number, dir: 1 | -1): number {
  let i = from;
  for (;;) {
    i += dir;
    if (i < 0 || i >= options.length) return from;
    if (!options[i]?.disabled) return i;   // 自動略過 disabled
  }
}

// typeahead：500ms 內連打累積成 buffer，比對 label 開頭
function onTypeahead(char: string) {
  typeBuffer += char.toLowerCase();
  const match = options.findIndex(o => !o.disabled &&
    o.label.toLowerCase().startsWith(typeBuffer));
  if (match >= 0) { if (!isOpen) open(); setActive(match); }
}

// 每個實例用 Vue 3.5 useId() 產生穩定唯一 id，串起 ARIA 關聯
const uid = useId();
const listboxId = `${uid}-listbox`;
const optionId = (i: number) => `${uid}-option-${i}`;
```

# v4 · 相對 v3 的差異

| 面向 | v3 | v4 |
| --- | --- | --- |
| 鍵盤操作 | ❌ 只能滑鼠點 | ✅ 方向鍵 / Home / End / Enter / Esc / typeahead |
| 焦點 | ❌ 不可 Tab 聚焦、無 focus ring | ✅ 可聚焦、focus ring、關閉收回焦點 |
| ARIA 語意 | ❌ 純 div/ul/li | ✅ `combobox` + `listbox` + `option` |
| 高亮驅動 | CSS `:hover` | `activeIndex`（鍵盤 / 滑鼠一致） |
| 對外 API | — | **與 v3 相同（可直接替換）** |
