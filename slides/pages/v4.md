# v4 — 鍵盤操作與無障礙

補回 v1 原生 `<select>` 本有、v2 改自訂 `<div>` 後遺失的能力

---
layout: two-cols-header

# v4 · 設計目標

<div class="text-sm opacity-70 -mt-2">讓自訂 Select 用純鍵盤與螢幕閱讀器也能完整操作，API 一個字都不用改</div>

::left::

**要還的債**

- v1 原生 `<select>` 免費附送：可 `Tab` 聚焦、
  方向鍵移動、打字跳項、`Enter` / `Esc` 開合、
  螢幕閱讀器語意
- v2 改自訂 `<div>` 取回外觀主導權，**這些全丟了**
- v3 忙著解 overflow 裁切，未觸及這塊

::right::

**怎麼還**

- ✅ **鍵盤操作**：方向鍵 / `Home` / `End` / `Enter` / `Esc` / typeahead
- ✅ **焦點管理**：`Tab` 聚焦、focus ring、關閉收回焦點
- ✅ **ARIA 語意**：`combobox` + `listbox` + `option`
- ✅ 對外 API 與 v3 **完全相同**（import `@v3` → `@v4`）

<div class="pt-2 text-sm opacity-60">
→ 自訂面板終於補齊原生本有的可及性（accessibility）
</div>

# v4 · 鍵盤操作對照表

<div class="text-sm opacity-70 -mt-2">聚焦 trigger 後（disabled 時移出 tab 序）</div>

| 按鍵 | 行為 |
| --- | --- |
| `↓` / `↑` | 關閉時開啟面板；開啟時上下移動高亮 |
| `Home` / `End` | 跳到第一 / 最後一個可選項 |
| `Enter` / `Space` | 開啟面板，或選取目前高亮項 |
| `Esc` | 關閉面板，焦點收回 trigger |
| `Tab` | 關閉面板並放行預設行為（焦點自然離開） |
| 可列印字元 | **typeahead**：跳到 label 符合開頭的選項 |

<div class="pt-2 text-sm opacity-60">
鍵盤導覽**自動略過 <code>disabled</code> 選項**；高亮超出可視區時自動 <code>scrollIntoView</code>
</div>

# v4 · 相對 v3 的差異

| 面向 | v3 | v4 |
| --- | --- | --- |
| 鍵盤操作 | ❌ 只能滑鼠點 | ✅ 方向鍵 / Home / End / Enter / Esc / typeahead |
| 焦點 | ❌ 不可 Tab 聚焦、無 focus ring | ✅ 可聚焦、focus ring、關閉收回焦點 |
| ARIA 語意 | ❌ 純 div/ul/li | ✅ `combobox` + `listbox` + `option` |
| 高亮驅動 | CSS `:hover` | `activeIndex`（鍵盤 / 滑鼠一致） |
| 對外 API | — | **與 v3 相同（可直接替換）** |

<div class="pt-3 text-sm opacity-60">
完整差異記錄於 <code>src/packages/v4/CHANGELOG.md</code>
</div>
